# Optical Alignment Tools

Conjunto de algoritmos en MATLAB para el procesamiento y análisis de interferogramas, diseñado para asistir en procesos de Ensamblaje, Integración y Pruebas (AIT) de componentes ópticos.

El script `interferogram_generator.m` simula el patrón de franjas obtenido en un banco óptico (ej. interferómetro de Fizeau) combinando el mapa del frente de onda (Wavefront Error - WFE) con aberraciones específicas como inclinación (Tilt) y aberración esférica (Zernike).

## Uso
Ejecuta `interferogram_generator.m` en MATLAB para renderizar el mapa 3D del frente de onda y generar el patrón de interferencia 2D resultante.
